# Security

## Supported versions

Only the latest commit on `main` and the most recently published release
are supported. HUPI is self-hosted — if you're running an older build,
update before reporting an issue that a newer version may already fix.

## Reporting a vulnerability

Open a [GitHub Issue](https://github.com/hupi-dev/hupi/issues) describing
the vulnerability. Include what you found, how to reproduce it, and its
impact if known.

Tier 3 (`hupi-t3`) is a separate, private repo — if the vulnerability is
specific to Tier 3, still open the issue here, or email
[work@hupi.dev](mailto:work@hupi.dev) if you'd rather not describe it
publicly before a fix ships.
